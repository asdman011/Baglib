# Maktabook.app — Islamic study notes research

Date: 2026-11-05. Agent: Claude Code. Design input for `PDF and Notes Experience Plan.md`.

## Method and limits

Web app; only the public landing page maktabook.app was read (2026-11-05). No account was created and the app was not used, so everything below is as advertised, not observed.

## Advertised features

- "Study Your Deen Without Switching Tabs": Quran and hadith are inserted into the note being written.
- Quran Reference: a single ayah, a range or a whole surah. Hadith Reference: by number or by searching major collections; samples show narrator, in-book reference and grade.
- Arabic support: right-to-left writing, a built-in font, script control. Interface in English, Arabic and French.
- Islamic honorifics expand while typing.
- PDF Split View: a PDF beside the note.
- Notebooks with sub-pages and tags. Import Markdown, ZIP, TXT; export PDF, Markdown, DOCX; read-only share link.
- Interaction: commands typed inside the note insert content in place.

Not mentioned: highlighting, annotations, flashcards or review.

## Fit for BagLib

This is the product closest to BagLib's audience. BagLib already has typed `quran:` and `sunnah:` links and embeds, local Quran and Sunnah data with grades, and a split reader. Gaps: a command that searches ayahs and hadith while typing and inserts the text with its reference, ayah ranges (`quran:hafs:2:255` is a single ayah today), honorific expansion, and Markdown or DOCX export of a notebook. BagLib goes further on highlights, SRS and history, none of which Maktabook advertises.
