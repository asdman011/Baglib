## Small fixes implemented

- AIResearchService no longer writes a generated answer into annotations. A legacy caller setting saveAsNote cannot bypass review. Reader's pre-generation save button is removed; displayed output is saved only by the separate save action.
- Chat/study accepted notes, cards and manuscript insertions retain localized AI-generated text. Existing explain-back marks its AI judgment portion, preserving the learner's own summary. Curriculum stores its marker in the existing description; original names and titles remain untouched.
- Active chat/study and reader panels show a localized recall nudge and uncertainty/no-fatwa notice, using readable line height and logical spacing. The older reader now derives RTL/LTR from the interface direction.
- AIProviderService appends the same no-fatwa/uncertainty/untrusted-source guidance to all LLM requests; output formatting and original source text remain unchanged. This is prompt guidance, not a model-output guarantee or a fatwa classifier.
- Legacy research, old editor AI and curriculum main paths reject unconsented current remote providers; reader/curriculum reuse the existing consent dialog. LLM translation also checks enabled/consent. Dedicated translation failure no longer switches providers implicitly.
